## install
* wsl --install
* wsl --install --web-download
* wsl --install Ubuntu-24.04

## uninstall
* wsl --unregister Ubuntu-24.04

## view
* wsl --list
* wsl --list --online
* wsl --list -v

## default
* wsl --set-default Ubuntu-24.04

## run
* wsl -d Ubuntu-24.04

## quit
* exit

## backup
* wsl --export Ubuntu-24.04 ubuntu.tar
